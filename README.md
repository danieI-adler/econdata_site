## 📌 Sobre o Projeto

O **EconData Analytics** é o núcleo discente de inteligência analítica e ciência de dados do Departamento de Economia da PUC-Rio. Desenvolvemos capacitação prática em programação estatística, inteligência artificial, bancos de dados e modelagem econométrica, conectando os alunos às principais instituições do mercado de capitais e consultorias.

---

## 🚀 Destaques da Plataforma

- **Console R Interativo (WebAssembly / WebR)**: Ambiente R completo rodando 100% no navegador do visitante sem necessidade de servidores externos.
- **Gráficos em Tempo Real com `ggplot2`**: Renderização nativa de visualizações estatísticas, com suporte a download em PNG e modo tela cheia.
- **Assistente IA de Código R**: Integração cliente-side com modelos generativos (Gemini 3.5 Flash Lite) para transformar comandos em linguagem natural em scripts R e gráficos instantâneos.
- **Tema Dual (Claro & Escuro)**: Interface moderna com alternância entre Dark Mode (padrão) e Light Mode com persistência local.
- **Projetos & Pacote `brfinance`**: Documentação e casos práticos de finanças quantitativas e séries temporais do Banco Central (SGS).

---

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5 Semântico, CSS3 Modular (Design System responsivo) e Vanilla JavaScript (ESModules).
- **Computação Estatística**: [WebR](https://docs.r-wasm.org/webr/latest/) (R compilado para WebAssembly).
- **Hospedagem & CI/CD**: GitHub Pages com deploys automatizados via GitHub Actions.
